FOR WINDOWS LOCAL PROJECT FOLDER
1. Back up E:\Default Project\adnan-funnel (or wherever your existing project lives).
2. Extract the full ZIP into E:\Default Project\. It contains an adnan-funnel folder.
   If overwriting existing files, keep a backup of .env and data\leads.db first.
3. In PowerShell: cd "E:\Default Project\adnan-funnel"
4. If you do not have a .env, copy .env.example to .env, then edit the .env privately.
5. REQUIRED before exposing the site publicly:
   - Set strong, unique ADMIN_PASSWORD (16+ characters).
   - Set RESEND_API_KEY to your NEW private key, not the revoked key.
   - Set CAL_WEBHOOK_SECRET and configure a matching Cal.com webhook when public.
   - Confirm CONTACT_EMAIL=nothinggamer03@gmail.com.
   - Check CAL_CLIENT_URL and CAL_RECRUITER_URL are your actual Cal.com links.
6. Run: npm run check
7. Run: npm test
8. Run: npm start
9. Open http://localhost:3000 and http://localhost:3000/admin/
   If port 3000 is in use, identify the existing Node process before restarting.

IMPORTANT DEPLOYMENT NOTE
A pure static/Vercel static upload of site/ does NOT run the Node.js API, SQLite
lead database, admin login, webhook endpoint, or Resend notifications. For these
features, deploy the entire project to Node-compatible hosting with persistent
storage and HTTPS. DO NOT upload .env into a public/static web directory.
