# SEO implementation and content backlog

## Already implemented in source

- Unique human-written title and description for homepage, recruiter page and six service pages.
- Indexable HTML visible without JS; descriptive headings, service differentiation, internal links and contextual CTAs.
- Canonical URLs targeting the primary domain; robots.txt, XML sitemap, noindex on admin.
- Schema.org `Person` on homepage, `ProfilePage` on recruiter page, and `Service` on service pages.
- Privacy notice and legitimate contact information.

## Site architecture

- `/` — discover both audience paths and focused services.
- `/services/{service}/` — unique service scope, problems, supported capabilities, relevant tools and booking CTA.
- `/recruiters/` — recruiter intent, seven jobs, degree, tools, downloadable CV and interview request.
- `/privacy/` — information handling; `/admin/` is intentionally excluded from indexing.

## Keyword targeting
